## Built during the hackathon

- **Layout engine** (`shared/geometry/`, `shared/layout/`): integer-millimetre footprints with quarter-turn rotation, wall and collision checks, keep-clear exit zones, free-spot search, seat and cost summary, layout diff.
- **Planner** (`server/lib/planner/`): deterministic theatre-row and banquet-table planners that keep locked and fixed objects in place, enforce a minimum aisle and report shortfalls.
- **Proposals and history** (`server/lib/proposals/`, `server/lib/versions/`): proposals bound to a base version, stale-proposal refusal, version snapshots and restore.
- **17 actions** (`actions/`) and their contracts (`shared/contracts/`), with version checks and an audit row on every write.
- **Setup packs** (`shared/export/`, `server/lib/exports/`): frozen versions rendered as an SVG plan with dimensions, scale bar and north arrow, an item list, seating rows, placements and printable HTML, plus PNG export in the browser.
- **The whole UI** (`app/`):
  - landing page and guest flow;
  - events list with plan thumbnails;
  - the 2D floor plan with drag, marquee, keyboard and inspector;
  - the 3D view (`shared/scene/` maps plan objects to 3D blocks);
  - proposal review with before and after numbers;
  - history, setup-pack page, and screen-aware agent prompts.
- **Guest sandboxes** (`server/lib/guests/`, `server/lib/demo/`): per-visitor seeded events, expiry, and SQL rate limits on demo starts and guest agent messages.
- **Tests** (`tests/`): 82 tests across geometry, both planners, layout summary and diff, export rendering, 3D blocks, the demo seed, rate limits and agent prompts.
- **Deployment** (`deploy/vps/`): the live server, adapted from Orvane's scripts as listed above.
